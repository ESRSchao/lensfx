# Security Policy

## Supported versions

The `main` branch and the latest GitHub Release receive fixes.

## Reporting a vulnerability

Please open a [private security advisory](https://github.com/ESRSchao/lensfx/security/advisories/new)
or an issue without attaching exploit code.

The local server binds `127.0.0.1` only and is not a public web service.
Do not expose `--host 0.0.0.0` on an untrusted network.
